# E-commerce-Sales-Analysis-Dashboard-Power-BI-
Analysis of 15.69K orders generating ₹1.25Bn in revenue, built as an interactive Power BI dashboard to track product, category, regional, and quarterly sales trends.

 What's in this project

- data — raw order data used to build the dashboard
- dashboard — the Power BI (.pbix) file
- screenshots — preview images of the dashboard

 Key Metrics Tracked

- Average Order Value (AOV)
- 29.72% order cancellation rate
- ₹525.42M in lost revenue from cancellations
- Product, category, regional, and quarterly sales trends

 Tools Used

Power BI — Data Modelling, DAX, Slicers, Interactive KPI Dashboard
